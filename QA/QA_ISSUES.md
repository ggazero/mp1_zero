# MP1 QA 문제 기록

이 파일은 체크리스트에서 FAIL이 나온 문제를 자세히 기록할 때 사용합니다.

테스트 중에는 코드를 고치지 말고 먼저 문제를 모두 기록합니다. 수정이 끝난 뒤 같은 순서로 다시 테스트하고 재테스트 결과를 추가합니다.
